# 🎮 PokéExplorer App

## Descripción
PokéExplorer es una aplicación web desarrollada en React que permite explorar información sobre Pokémon consumiendo de manera asíncrona la API pública [PokéAPI](https://pokeapi.co/). Los usuarios pueden navegar por la lista principal, ver detalles de cada personaje mediante rutas dinámicas, consultar sus habilidades/reseñas mediante subrutas anidadas y guardar sus Pokémon preferidos utilizando un estado global persistente.

## API Utilizada
- **PokéAPI**: https://pokeapi.co/
